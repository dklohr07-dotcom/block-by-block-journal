Mind Reset Hub visual patch

This ZIP is intentionally small so it can be uploaded to GitHub without replacing the rest of the app.

Upload/commit these files into the same paths in your repository:
- mind-reset-hub.html
- custom-backgrounds/card-diamond.png
- custom-backgrounds/card-breathing.png
- custom-backgrounds/card-rain.png
- custom-backgrounds/card-miner.png
- custom-backgrounds/card-campfire.png
- custom-backgrounds/card-biome.png
- custom-backgrounds/card-forest.png
- custom-backgrounds/card-sunset.png
- custom-backgrounds/card-cave.png
- public/sounds/ES_Weather, Thunder, Light Rain - Epidemic Sound.mp3

The patch keeps the Mind Reset Hub isolated to mind-reset-hub.html and its assets. It does not include index.html, server.js, package.json, or any app-wide files.
