# Block by Block Journal Web App

Minecraft-inspired, mobile-friendly journaling and mind-reset app for youth.

## Run locally
```bash
npm install
npm start
```
Open `http://localhost:3000`.

## Deploy to Railway
Upload this folder to GitHub, connect the repository to Railway, and deploy. No environment variables are required for this static version.

## Notes
Journal entries, mood check-ins, XP, badges, and safe-base plans save in the browser using localStorage. This is privacy-friendly for a prototype, but not intended as clinical care or emergency support.
