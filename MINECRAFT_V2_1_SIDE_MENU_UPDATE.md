# Minecraft V2.1 Side Menu Update

Updated `index.html` and `shared/minecraft-v2-theme.css`.

## Changes
- Added a fixed left-side Minecraft chest menu with hotbar-style active states.
- Removed the Today's Reminder card from the hero/header image area.
- Increased global body, paragraph, form, card, button, and heading sizes for readability.
- Added stronger Minecraft texture effects: chest wood side menu, pixel grid overlay, inventory slot buttons, XP bar, and improved chat-style toast.
- Added responsive mobile behavior: the side menu becomes a bottom hotbar.

## Run locally
```bash
npm install && npm run dev
```
