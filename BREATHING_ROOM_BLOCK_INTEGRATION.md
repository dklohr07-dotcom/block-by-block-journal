# BREATHING ROOM Block Integration

Integrated files:
- `realms/breathing.html`
- `custom-backgrounds/breathing-room-user-block.png`
- `custom-backgrounds/breathing-block-xl.png` (updated copy for compatibility)

Behavior:
- Inhale: the new block grows from `MIN_SCALE` to `MAX_SCALE`.
- Hold: the block stays at `MAX_SCALE`.
- Exhale: the block shrinks back to `MIN_SCALE`.
- The existing 4-breath completion flow and diamond reward remain intact.
