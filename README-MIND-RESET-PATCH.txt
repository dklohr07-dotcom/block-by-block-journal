Mind Reset Hub safe GitHub patch

Upload/copy these files into the root of your existing GitHub project. This patch is intentionally small so it does not overwrite the rest of the app.

It includes:
mind-reset-hub.html
custom-backgrounds/*
public/sounds/ES_Weather, Thunder, Light Rain - Epidemic Sound.mp3
shared/*, only if your current hub uses the shared realm helpers.

Recommended upload method:
Open your repo in GitHub, choose Add file > Upload files, drag the contents of this folder in, and commit. Do not delete or replace other project files.

The Rain Room sound path is:
public/sounds/ES_Weather, Thunder, Light Rain - Epidemic Sound.mp3

The Rain Room scene is zoomed out with CSS only, so the background image and controls stay separate and easy to adjust later.
